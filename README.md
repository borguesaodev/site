### 🚀 Funcionalidades

- **Tema escuro / claro** — alternância com persistência via `localStorage`
- **Header fixo** — aparece com efeito ao rolar a página
- **Navbar responsiva** — menu hambúrguer para mobile
- **Toggle de habilidades** — alterna entre Skills e Ferramentas
- **Formulário de contato** — integrado com [Formspree](https://formspree.io), com feedback visual de envio
- **Botão "Ir ao topo"** — aparece ao rolar a página
- **Links sociais** — GitHub, Instagram, LinkedIn com tooltips animados
- **Currículo para download** — link direto para PDF

# 💼 BorguesaoDev — Personal Portfolio

> Personal portfolio of **Alysson Borguesão**, Full-Stack Developer.  
> Built with pure HTML, CSS, and JavaScript — no frameworks, no heavy dependencies.

---

## 🇺🇸 English

### 🚀 Features

- **Dark / Light theme** — toggle with persistence via `localStorage`
- **Sticky header** — appears with an effect when scrolling
- **Responsive navbar** — hamburger menu for mobile
- **Skills toggle** — switches between Skills and Tools panels
- **Contact form** — integrated with [Formspree](https://formspree.io), with visual feedback on submission
- **"Go to top" button** — appears when scrolling down
- **Social links** — GitHub, Instagram, LinkedIn with animated tooltips
- **Resume download** — direct link to PDF
